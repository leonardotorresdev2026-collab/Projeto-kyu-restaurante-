# KYU — Versão oficial Supabase organizada

## Como abrir
1. Extraia o ZIP.
2. No VS Code, use Arquivo > Abrir Pasta e selecione `KYU-Supabase-oficial-organizado`.
3. Clique com o botão direito em `index.html` > Open with Live Server (ou Go Live).

## Arquivos
- `index.html` — página inicial
- `cardapio.html` — cardápio
- `style.css` — design e versão para celular
- `script.js` — animações e interações
- `assets/` — cópias locais das 8 imagens

## Imagens / Supabase
Esta versão referencia imagens hospedadas no Supabase por URL pública. As cópias locais em `assets/` foram preservadas, mas **não substituem automaticamente as URLs remotas**. Para um site que não dependa do Supabase, é preciso trocar as URLs das imagens nos HTMLs/CSS por caminhos `assets/photo-N.ext`.

## Hospedagem
Publique a pasta extraída no Netlify ou Cloudflare Pages. Confira os links externos e o carregamento das imagens após publicar.

O código original foi preservado, sem mudanças intencionais de layout ou funcionalidade.
